Stop your AI agent from drifting away from what you already agreed on.

One Markdown spec per capability, a one-line tag in the code that backs it, and a gate that checks the two still agree. Stdlib Python, no install, no AI SDK.

Three commands

python scripts/reqmap.py init

Set up requirements/ and draft one spec per capability from the code you have. Never clobbers a file you already have.

python scripts/reqmap.py gate

The verdict: do the code and the specs still agree? Report-only; wire it into your pre-commit hook and CI. --full adds every advisory check.

python scripts/reqmap.py sync

Rebuild everything derived: the drift baseline, the map, the findings. The only command that writes.

The drift it catches

A confirmed spec says greet(name) must now strip the spaces around name. The code was never touched. From the runnable demo, examples/hello-drift:

$ python ../../plugin/scripts/reqmap.py gate
WARN  RM018 HELLO-GREET-001: DRIFT — contract changed since lock; re-check 1 member(s): hello.py:1

1 requirements (1 confirmed, 0 legacy-schema), 1 members, 0 errors, 1 warnings.
...
gate: PASS — link sync + drift + test links, readability, map freshness (advice: `gate --full`).
