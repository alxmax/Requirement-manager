# Case studies

There is no published case study from a repository this project does not maintain.
The engine is dogfooded here, and `examples/hello-drift` shows one drift on purpose.
Neither is evidence that someone else kept it.

A write-up from a tree we have never seen is the document this page is for. Short is
enough. What it caught and what it missed is the part that matters; a compliment with
no repo behind it is not.

## Send one

Open an issue with the [I tried this on my repo](https://github.com/alxmax/requirement-manager/issues/new?template=tried-on-my-repo.yml)
template, or add a section below in a pull request. Say what we may quote. We will not
invent a testimonial to fill this page.

## Template

```markdown
## <project or team>, <month year>

Tree: <languages, rough file count, how many requirements you ended with>
How far: <watch only / a few confirmed requirements / the gate in CI>
Caught: <the drift or the gap that was real>
Missed: <what it did not see, or where you stopped>
Still using it: <yes / no, and why>
```
